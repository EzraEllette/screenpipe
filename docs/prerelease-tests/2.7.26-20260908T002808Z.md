## Scope and environment

Two disposable Orchard/Tart macOS 26.6.2 arm64 VMs on `mac-mini`, SIP disabled, 110 GB disks. Main app VM: 8 CPU/16 GB. Identity-only VM: 4 CPU/8 GB so two machines could coexist within worker resources. The second VM used a randomized serial and a verified different hardware fingerprint. Host apps were not used for acceptance.

Enterprise runtime requests went to an explicitly configured loopback QA fixture that could return successful identity acknowledgements, HTTP 503 and HTTP 409 and record actual uploaded JSONL. This verifies the packaged client's behavior against that protocol. It does **not** verify deployed authorization, production control-plane persistence, or an end-to-end hosted gateway. Gateway identity/search/image tests exercised the real gateway router and SQLite with in-memory object storage. Production hosted acceptance is **NOT TESTED**; this report is not full release sign-off.

Other-platform hardware behavior, Windows/Linux installers, Intel macOS, and UI-level settings-reset journeys are NOT TESTED. Settings removal/reinstall were controlled filesystem fixtures. The comparison also contains version bumps, audio-device documentation, and a coding-agent meeting-audio eval case; these introduce no additional shipped application behavior. That coding-agent eval suite was not run.
